# AgentTopology Lab: 다중 에이전트 협업 토폴로지 최적 설계기 & 인터랙티브 시뮬레이터

> **SKT ALEPH 1기 장진영 연구 논문 반영 애플리케이션 (과제 BR-B 실행 묶음)**

---

## 1. 기반 논문 정보 & 애플리케이션 한 문장 정의

- **기반 논문 제목**:
  `알고리즘 문제 해결 및 단위 테스트 검증에서 다중 에이전트 협업 토폴로지(순차형 vs 중앙 조율형 vs 토론형 vs 계층형)의 테스트 통과율 및 실행 지연시간 비교 실증`
- **저자**: 장진영 (SKT ALEPH 1기)
- **누구를 어떻게 돕는가 (BRB-C01, BRB-C03, BRB-C10)**:
  > **"본 애플리케이션은 LLM 기반 멀티 에이전트 시스템을 설계하는 개발자·연구자가 알고리즘 문제 해결 및 단위 테스트 파이프라인을 구축할 때, 4대 협업 토폴로지 실증 결과(중앙 조율형 통과율 88.0% 및 토론형 대비 지연시간 40% 절감 등)를 바탕으로 요구 조건에 최적화된 협업 토폴로지를 진단·비교하고 시뮬레이션해 줍니다."**

---

## 2. 사용자가 할 일 세 가지 (BRB-C02, BRB-C05, BRB-C13)

1. **할 일 1. 요구 조건 설정 & 실시간 진단 (Goal & Constraints)**:
   - 대상 문제 난이도(Easy / Medium / Hard), 목표 단위 테스트 통과율(%), 최대 허용 지연시간(ms), 에이전트 인원 수, 최적화 우선순위를 입력/조정합니다.
   - _안전 가드(Safe Fallback)_: 음수나 100% 초과, 텍스트 등 비정상 값을 입력해도 애플리케이션이 절대 멈추지 않고 안전한 수치로 자동 보정됩니다.
2. **할 일 2. 논문 200회 실측 데이터 기반 4대 구조 비교 (Topology Matrix)**:
   - 순차형(Linear), 중앙 조율형(Star), 완전 토론형(Debate), 계층형(Hierarchy) 4개 구조의 실측 지표(통과율, 지연시간, 토큰 소모량, 오류 회복 성공률)를 매트릭스로 확인하고 최적 토폴로지 추천 근거 리포트를 확인합니다.
3. **할 일 3. 실시간 협업 파이프라인 시뮬레이터 구동 & 오케스트레이션 설정 내보내기 (Live Simulation & Export)**:
   - 검증 대상 알고리즘 문제(Two Sum, 유효 괄호 검증, LRU 캐시 등)를 선택하고 `시뮬레이션 시작`을 눌러 에이전트 간 메시지 전달 및 단위 테스트 자가 수정 과정을 실시간 관찰합니다.
   - 검증 완료 후 `오케스트레이션 Config 복사/내보내기`를 통해 파이프라인 설정(JSON)을 추출합니다.

## 3. 새 임시 폴더에서 실행하는 방법 (BRB-C08, BRB-C09)

본 패키지는 외부 의존성 설치 없이 즉시 실행 가능한 독립형 정적 애플리케이션으로 패키징되어 있습니다.

### 방법 A. 브라우저에서 직접 열기 (가장 빠름)

1. 압축을 해제한 임시 폴더에서 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일 등 웹 브라우저로 엽니다.
2. 계정 생성, 로그인, 비밀번호, API 키 입력 없이 즉시 1분 안에 모든 기능을 사용해 볼 수 있습니다.

### 방법 B. 로컬 정적 웹서버로 실행 (선택 사항)

파이썬이 설치되어 있는 경우 터미널에서 다음 명령을 입력하여 로컬 서버를 구동할 수 있습니다:

```bash
# 압축을 푼 폴더에서 실행
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`으로 접속합니다.

## 4. 데이터 및 비밀값 정리 명세 (BRB-C06, BRB-C07, BRB-C12)

- **공개/예시 데이터 사용 (BRB-C06)**:
  - 검증용 알고리즘 문제는 공개 알고리즘 샘플이며, 사용된 성능 지표는 논문 200회 실험의 통계적 평균치입니다. 실제 개인정보(이름, 연락처, 주소 등)는 일체 포함되어 있지 않습니다.
- **비밀값 0건 (BRB-C07, BRB-C12)**:
  - 본 애플리케이션은 클라이언트 브라우저 실시간 결정론적 시뮬레이션 엔진으로 구동되므로, 소스코드 및 화면 어디에도 API Private Key, Secret Token, 데이터베이스 비밀번호가 존재하지 않습니다.
  - 별도의 외부 LLM API 호출을 연동하고자 할 경우 환경 변수(예: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`)를 통해 주입하도록 설계되어 있습니다.
