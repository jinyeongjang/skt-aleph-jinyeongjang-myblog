## 2. 자기소개서 (Cover Letter)

### 제목: 열쇠 없는 문을 지키는 법 — 비밀번호 너머의 신뢰를 짓다

2024년 11월 늦가을, 프로젝트를 진행하던 중 서비스에 예기치 못한 치명적인 오류가 발생했을 때 나는 얕은 기본기가 팀을 곤경에 빠뜨렸다는 참담한 무력감에 짓눌렸습니다.

부트캠프 프로젝트에서 나는 주로 리액트(React)를 활용한 프론트엔드 개발에 집중했습니다. 사용자 화면 구현에는 자신감이 있었지만, 백엔드와 연결되는 인프라와 네트워크 통신은 인터넷 블로그 설정을 복사해 붙여 넣은 블랙박스에 불과했습니다. 프로젝트 진행 중 예기치 못한 통신 오류가 터져 화면이 멈추었을 때, 시스템 로그 한 줄조차 해석하지 못하고 발만 굴렀습니다. 화면만 만들 줄 알았지 밑단의 통신 흐름을 몰랐던 미숙함으로 팀원들의 노력이 멈춰 서자, 나는 "다시는 원리를 모르는 코드를 쓰지 않고 끝까지 문제를 해결하겠다"고 결심했습니다.

실패는 뼈아팠지만 도망치지 않고 문제 해결에 매달렸습니다. 집 근처 스터디카페와 집에서 웹 통신과 기초 원리를 파고들며 "블랙박스 코드는 쓰지 않는다", "배포 전 사전 점검 루틴을 거친다"는 철칙을 세웠습니다. 화면에 머물던 시야를 밑단으로 넓혀 어떤 예기치 못한 오류 앞에서도 원인을 명확히 규명하겠다는 [자기동기력]을 품었고, 네트워크와 보안 인프라를 바닥부터 제대로 배우기 위해 SKT ALEPH 1기 과정에 도전했습니다.

이 결심은 SKT ALEPH 1기 13주 과정에서 만개했습니다. 첫째는 일상의 기복을 통제하는 [자기조절력]입니다. ALEPH 과정을 통해 시스템 소켓 원리, 서버 로그 분석, 패킷 덤프 추적을 배우며 네트워크와 보안관제 직무에 깊은 흥미를 갖게 되었습니다. 과거 프로젝트에서 겪었던 예기치 못한 통신 오류의 원인이 소켓 누수와 연결 제어 미흡이었음을 패킷 수준에서 스스로 규명하고 해결했을 때 배움의 확신을 얻었습니다. 최근에는 데이터 역량을 더하고자 SQLD 자격시험을 접수하며 도전을 이어가고 있습니다. 경남 양산에서 부산까지 왕복 3시간 거리 속에서도 새벽 5시 40분 첫 버스에 올랐고, 13주 동안 지각·결석 없이 매일 1등으로 도착해 예습과 복습을 완주했습니다.

둘째는 동료와 보폭을 맞추는 [대인관계력]입니다. 2026년 8월 11일 첫 수업에서 자원하여 조장을 맡아 심리적 안전감을 다졌고, Kali Linux 설치로 고전하던 동료의 곁을 지키며 환경 셋팅을 마쳤습니다. 2026년 9월 17일 조별 발표에서는 복잡한 3-Way Handshake를 어려워하던 팀원을 위해 직관적인 흐름도를 설계해 "대본 없이도 자신 있게 발표했다"는 감사를 받았습니다. 과거 2년간 디지털 배움터에서 눈높이를 맞추어 기술을 나누던 온기는 팀의 성장을 돕는 조력 리더십으로 이어졌습니다.

셋째는 바닥까지 규명하는 집요한 [자기동기력]입니다. 2026년 8월 26일 복잡한 코드 에러 앞에서 밑단 시스템 로그를 추적해 해결했고, 과제 8 WebAuthn 패스키 인증 구현 시 브라우저 서명 포맷과 Web Crypto API 간 바이트 불일치를 W3C RFC 명세를 분석해 직접 바이트 파서를 구현하여 해결했습니다. 리액트로 다진 웹 개발 역량 위에 ALEPH에서 익힌 네트워크, 시스템 소켓, 패킷 분석 및 보안관제 지식을 결합하며 실질적인 문제 해결력을 증명하고 있습니다.

어떤 복잡한 오류 앞에서도 바닥부터 원리를 파고드는 집요함과 사람을 향한 따뜻한 책임감으로, 팀이 믿고 맡길 수 있는 가장 견고한 보안·인프라 환경을 완성하겠습니다.
